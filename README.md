# ShoppyGlobe 🛒

ShoppyGlobe is a React-based e-commerce web application that allows users to browse products, view detailed product information,
add items to a shopping cart, and proceed to checkout. The application is fully responsive and works seamlessly across desktop, 
tablet, and mobile devices.

Visit the site now at : https://sandeepgudme.github.io/
---

![image alt](https://github.com/Sandeepgudme/E-commerce/blob/main/Screenshot%202026-01-01%20084720.png?raw=true)

## 🚀 Features

- Product listing fetched from external API
- Search products by name
- View product details
- Add and remove items from cart
- Cart item count in header
- Checkout page with total price calculation
- Responsive design (desktop, tablet, mobile)

---

## 🛠️ Technologies Used

- React.js
- Vite
- Redux Toolkit
- React Router DOM
- JavaScript (ES6)
- CSS (Flexbox & Grid)
